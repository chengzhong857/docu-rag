# Transformer 与注意力机制

## 一、注意力机制的基本形式

注意力机制可以理解为一次软性的信息检索：给定查询 Q（Query）、键 K（Key）、值 V（Value），用 Q 与每个 K 计算相关性得分，softmax 归一化为权重，再对 V 做加权求和。

缩放点积注意力的公式为 Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) V。这里除以 sqrt(d_k) 是关键细节：当维度 d_k 较大时，Q 与 K 的点积方差随之增大，softmax 会进入饱和区，梯度变得极小。除以维度的平方根可以把方差拉回 1 附近，让训练稳定。

## 二、自注意力与多头注意力

自注意力（Self-Attention）指 Q、K、V 都来自同一个序列，让序列内每个位置都能看到其他所有位置，从而建模长距离依赖。这是 Transformer 与传统循环网络最本质的区别：RNN 必须逐步传递信息，长距离依赖的路径长度是 O(n)，而自注意力的路径长度是 O(1)。

多头注意力（Multi-Head Attention）把 d_model 维分成 h 个头，每个头在低维子空间里独立做注意力，最后拼接再线性投影。它的意义在于让模型同时从多个表示子空间捕捉不同类型的关系，比如有的头关注语法依存，有的头关注指代关系。常用的头数是 8 或 12。

## 三、位置编码

自注意力本身是置换不变的，打乱输入顺序结果不变，因此必须额外注入位置信息。

正弦位置编码用不同频率的正弦和余弦函数生成固定编码，可以直接加到词向量上，优点是能外推到训练时没见过的长度，不需要学习参数。

可学习位置编码把位置向量作为参数训练，实现简单，但无法处理超出最大长度的序列。

旋转位置编码（RoPE）通过旋转矩阵把相对位置信息编码进 Q 和 K 的内积中，使注意力天然感知相对距离，是 LLaMA、Qwen 等现代大模型的标准做法，外推能力较好。

## 四、编码器与解码器的区别

编码器结构（BERT 类）使用双向注意力，每个位置可以看到整个序列，训练目标是掩码语言模型，即随机遮住部分 token 让模型预测。它擅长理解类任务：文本分类、命名实体识别、语义相似度、抽取式问答。

解码器结构（GPT 类）使用因果掩码，每个位置只能看到左侧的 token，训练目标是自回归预测下一个 token。它擅长生成类任务：对话、续写、代码生成。

编码器-解码器结构（T5、BART）同时具备两侧，编码器理解输入，解码器通过交叉注意力读取编码器输出并生成，适合翻译、摘要这类输入输出都是序列的任务。

## 五、复杂度与长文本瓶颈

自注意力的时间与显存复杂度都是 O(n^2 · d)，n 为序列长度。序列翻倍，注意力矩阵的大小变四倍，这是长文本处理的核心瓶颈。

主要的改进方向有三类。第一类是稀疏注意力，限制每个位置只与部分位置交互，把复杂度降到 O(n log n) 或 O(n)。第二类是线性注意力，用核函数近似 softmax，把复杂度降到 O(n)。第三类是分块与记忆机制，比如滑动窗口注意力配合全局 token。

工程上更常用的做法是 FlashAttention：它不改变数学结果，而是通过分块计算和在线 softmax 避免把完整注意力矩阵写入显存，在 GPU 上可获得数倍加速并大幅降低显存占用。

## 六、训练与推理的工程要点

预训练阶段常用掩码语言建模或下一 token 预测作为目标，代价是数据量需求极大。

微调阶段分为全参数微调和参数高效微调。LoRA 只训练低秩分解矩阵，可训练参数通常降到原来的 1% 以下，显存需求大幅下降，是目前最主流的微调方式。QLoRA 进一步把基座模型量化到 4bit，使单卡微调 7B 模型成为可能。

推理阶段有两个关键优化。KV Cache 缓存已计算的键和值，避免自回归生成时重复计算，代价是显存随序列长度线性增长。量化把权重和激活从 FP16 降到 INT8 或 INT4，显著减少显存和带宽需求，但可能带来精度损失，需要评估。
